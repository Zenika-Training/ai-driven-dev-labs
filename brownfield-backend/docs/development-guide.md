# Development Guide

## Getting Started

### Prerequisites

- **Java 21**: Download from [Oracle](https://www.oracle.com/java/technologies/downloads/) or [OpenJDK](https://openjdk.org/)
- **Maven**: Included via Maven wrapper (./mvnw)
- **IDE**: IntelliJ IDEA, Eclipse, or VS Code with Java extensions
- **Git**: For version control

### Setup

1. **Clone the repository:**
```bash
git clone <repository-url>
cd ai-driven-dev/brownfield-backend
```

2. **Build the project:**
```bash
./mvnw clean install
```

3. **Run the application:**
```bash
./mvnw spring-boot:run
```

4. **Verify it's running:**
- Application: http://localhost:8080
- Swagger UI: http://localhost:8080/swagger-ui.html

## Development Workflow

### 1. Making Changes

#### Adding a New Entity

1. **Create the Entity class** in a new package (e.g., `com.petclinic.owner`)
2. **Create the Repository interface**
3. **Create the Service class**
4. **Create the Controller class**
5. **Update data.sql** with schema and test data

Example:
```java
// 1. Entity
@Entity
public class Owner {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String firstName;
    private String lastName;
    
    // Constructors, getters
}

// 2. Repository
public interface OwnerRepository extends JpaRepository<Owner, Long> {
    List<Owner> findByLastName(String lastName);
}

// 3. Service
@Service
public class OwnerService {
    private final OwnerRepository ownerRepository;
    
    public OwnerService(OwnerRepository ownerRepository) {
        this.ownerRepository = ownerRepository;
    }
    
    public List<Owner> findAll() {
        return ownerRepository.findAll();
    }
    
    public Owner save(Owner owner) {
        return ownerRepository.save(owner);
    }
}

// 4. Controller
@RestController
@RequestMapping("/api/v1/owner")
public class OwnerController {
    private final OwnerService ownerService;
    
    public OwnerController(OwnerService ownerService) {
        this.ownerService = ownerService;
    }
    
    @GetMapping
    public List<Owner> findAll() {
        return ownerService.findAll();
    }
    
    @PostMapping
    public Owner save(@RequestBody Owner owner) {
        return ownerService.save(owner);
    }
}
```

#### Updating Database Schema

Edit `src/main/resources/data.sql`:

```sql
-- Add new table
CREATE TABLE IF NOT EXISTS owner (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    first_name VARCHAR(255) NOT NULL,
    last_name VARCHAR(255) NOT NULL
);

-- Add test data
INSERT INTO owner (first_name, last_name) VALUES ('John', 'Smith');
```

### 2. Testing

#### Writing Unit Tests

Create test file: `src/test/java/com/petclinic/{domain}/{ClassName}Test.java`

```java
@SpringBootTest
class VetServiceTest {
    
    @Autowired
    private VetService vetService;
    
    @Test
    void testFindAllVets() {
        // given
        
        // when
        List<Vet> vets = vetService.findAll();
        
        // then
        assertThat(vets).isNotEmpty();
    }
}
```

#### Running Tests

```bash
# Run all tests
./mvnw test

# Run specific test class
./mvnw test -Dtest=VetServiceTest

# Run specific test method
./mvnw test -Dtest=VetServiceTest#testFindAllVets

# Run with coverage
./mvnw test jacoco:report
```

### 3. Building

```bash
# Clean and build
./mvnw clean package

# Skip tests
./mvnw clean package -DskipTests

# Build without running tests but compile them
./mvnw clean package -Dmaven.test.skip=false
```

### 4. Running

```bash
# Run via Maven
./mvnw spring-boot:run

# Run the JAR directly
java -jar target/brownfield-backend-0.0.1-SNAPSHOT.jar

# Run with specific profile
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

## Configuration

### Application Properties

Located in `src/main/resources/application.properties`

Common configurations:
```properties
# Server port
server.port=8080

# Database
spring.datasource.url=jdbc:hsqldb:mem:petclinic
spring.datasource.driver-class-name=org.hsqldb.jdbc.JDBCDriver

# JPA
spring.jpa.show-sql=true
spring.jpa.hibernate.ddl-auto=none

# Logging
logging.level.com.petclinic=DEBUG
```

### Environment-Specific Configuration

Create profiles:
- `application-dev.properties`
- `application-prod.properties`


## Troubleshooting

### Port Already in Use

Change port in `application.properties`:
```properties
server.port=8081
```

### Build Failures

```bash
# Clean Maven cache
./mvnw clean

# Purge local repository
./mvnw dependency:purge-local-repository

# Update dependencies
./mvnw dependency:resolve
```

### Tests Failing

```bash
# Run single test to isolate issue
./mvnw test -Dtest=VetServiceTest

# Check test output in target/surefire-reports
```

### Application Won't Start

1. Check Java version: `java -version` (should be 21)
2. Check logs in console output
3. Verify port 8080 is available
4. Check database initialization in logs

## Performance Tips

1. **Use appropriate fetch strategies** for JPA relationships
2. **Avoid N+1 queries** by using JOIN FETCH when needed
3. **Use pagination** for large result sets
4. **Cache frequently accessed data** if needed
5. **Profile the application** to identify bottlenecks

## Security Considerations

Currently, the application has no authentication. For production:

1. Add Spring Security
2. Implement JWT authentication
3. Add role-based access control
4. Validate all inputs
5. Use HTTPS
6. Protect against SQL injection (JPA helps)
7. Implement rate limiting
