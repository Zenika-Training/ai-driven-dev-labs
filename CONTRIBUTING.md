# Contributing to AI Driven Dev Labs

This repository serves as the starting point for the practical portion of the AI Driven Development training and are meant to be used with the instructions found in [this repository](https://github.com/Zenika-Training/ai-driven-dev-instructions).

There is both a frontend and backend portion in the labs. Javascript is the only frontend option, however, for the backend portion, each language the labs can be done in has its own branch:
- main = java backend
- nodejs
- python 

These branches are not meant to be rebased, each branch can be fixed or improved upon independently.
